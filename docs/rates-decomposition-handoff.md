## 0. 为什么要这几个指标（分析背景）

长端收益率的标准分解：

```
长端名义 = 长期中性实际利率(R*) + 通胀预期 + 期限溢价(Term Premium)
```

面板现在只能看到**名义收益率本身**和 **BEI（通胀补偿）**。看到 10Y / 30Y 上行时，答不了「动的是通胀那一块，还是实际利率那一块」——而这两者的资产含义完全相反。

补完之后能跑通两刀：

```
第一刀  名义 − BEI → 实际收益率        判断:通胀因素 vs 实际利率因素
第二刀  实际 里再分 R* vs 期限溢价      判断:长期中枢上移 vs 久期风险补偿上升
```

**当期最想验的一个具体问题**：2026 年 8 月这轮 30Y 上行（一度触 5.34%），有观点认为核心动力是**期限溢价的结构性重估**（对财政与制度不确定性的补偿），不是通胀、不是政策路径。验法：

| 若 30Y BEI 基本不动 + 30Y 实际大幅上行 | 与该归因一致 |
|---|---|
| 若 30Y BEI 也在涨 | 该归因要打折 |

⚠️ **注意 30Y 这个期限**：业界常用的 ACM 期限溢价模型**只发布 1–10 年**，30Y 段没有公开模型序列。而面板的 BEI 曲线**有 30Y 档**——所以「名义 − BEI = 实际」这条路，是目前唯一能对 30Y 段做成分拆解的手段。这也是下面档一优先级最高的原因。

### 档三 · 两个新 fetcher（要真写代码）

#### 3a. ACM 期限溢价 + **预期短端均值**（纽约联储，**不在 FRED**）

- 源：纽约联储 Data & Indicators → Treasury Term Premia
- 覆盖：**1–10 年**，1961 至今，日频 + 月频，**每周更新**
- 同一份数据里包含三样：期限溢价、fitted yields、**expected average level of short-term interest rates**

**第三样才是这一档的真正价值**：它是「未来 N 年短端利率的预期平均」——也就是分解式里那条**预期腿**。有了它，`长端 = 预期腿 + 期限溢价` 这个分解就不用估了，两边都有数。

参照写法：`fetchers/mofJgb.ts`（外部官方文件现拉）或 `fetchers/capeShiller.ts`（抓外部页）。

⚠️ 只到 10 年 —— **30Y 段仍然只能靠档一的「名义 − BEI」**。

#### 3b. HLW `R*`（纽约联储，季频）

- 源：纽约联储 `research/policy/rstar`，Excel 下载
- **一年只发 4 次**：2026 年为 3/2 · 3/20、6/1、8/28、11/27（已核实）
- 提供**两套** Excel：`real-time estimates` 与 `current model estimates`

⚠️ **两套并存本身就是官方在承认历史值会被回改。** 做回测 / 历史分位必须用 **real-time** 那套，否则是前视偏差（look-ahead bias）——你会拿「后来才知道的 R\*」去评判「当时的决策」。日常看盘用 current 即可，但字段要标明是哪一套。

**优先级最低**：季频、要处理两版口径、且 `R*` 在日常读盘里用得最少。

## 3. 必须遵守的口径纪律

**① 估计值和价差不能视觉同级。**

`BEI` / `real` / `treasury` 是**从市场价格减出来的**——两条腿都有人在交易，你完全知道口径。
`ACM TP` / `THREEFYTP10` / `HLW R*` 是**某个模型的输出**——减号右边那个东西（预期路径均值、中性利率）**没有对应的可交易证券**。

后果不同：
- BEI 出错，错的是**解释**（它捆着通胀风险溢价和 TIPS 流动性溢价，数字本身是对的）
- 期限溢价出错，错的是**数字本身**（预期路径模型错多少，它就吸收多少）

所以面板上**必须视觉区分**（不同分组 / 加标注 / 不同线型），否则同为「百分点」的它们看起来像同级数据。

**② 两个期限溢价模型都接是好事，别二选一。**
Kim-Wright（Board）与 ACM（纽约联储）同一天可以差不少——美联储自己的 FEDS Notes 就写过不同模型的长期限估计 "can nevertheless differ materially at times"。**两条并排显示，分歧带宽本身就是置信度。** 反过来只报单一模型的点估计是误用。

**③ BEI 有个方向陷阱，实现时不必处理但面板注释值得写。**
官方分解是 `通胀补偿 = 预期通胀 + 通胀风险溢价 − TIPS流动性溢价`（**减号**）。
TIPS 流动性变差 → TIPS 收益率被推高 → **测得的 BEI 被压低**。
所以陷阱在**BEI 下跌**那一侧：看到 BEI 跌，先排除 TIPS 流动性恶化，而不是看到 BEI 涨才去查流动性。
另：十几 bp 量级的 BEI 变动可能完全落在这两项噪声内，不足以支撑「通胀预期在降」。

**④ 频率差异要在面板上显式化。**
`BEI`/`real`/`T5YIFR`/`THREEFYTP10` 日频；`ACM` 日频但**周更**；`HLW` **季频**。
把季频序列放进日频面板当同级线读会误导。

**⑤ `treasury[t] − real[t] ≈ bei[t]` 只是近似相等。**
`buildBei` 用的是 `subtractAligned`（按日前向填充对齐）。三条曲线各自独立拉、各自可能有缺日，所以别在前端写死这个恒等式做校验，也别用它去补缺失值。

### §5 那条开放问题的答案：**KW 的预期短端腿不必抓 ACM 就能得到**

`THREEFY10`（Fitted Yield on a 10 Year Zero Coupon Bond，Kim-Wright 同一模型）**在 FRED 上**，


**不必为这条腿去写纽约联储那个 fetcher** —— 这正是 §5 预判的「若有，档三 3a 的价值会下降」。

## 7. HLW r\* 落地（同日追加）

### 为什么这条的优先级被推翻

文档 §2 把 HLW 排最低，理由是「季频 + 要处理两套口径」。实际探过之后两条都不成立：

- **只做 `current` 就没有两套口径的问题。** `real_time` 的价值只在回测时兑现，现在没有回测需求；
  那份 1.8 MB、每个 vintage 一张 sheet，为不存在的需求付解析成本不值。
- **纽约联储发的是 `.xlsx` 不是 `.xls`。** xlsx = zip + XML，`fflate` **本来就在依赖里**
  （`fetchers/jpxJgbVix.ts` 已经是这个解法）。零新依赖。

## 8. 为什么最终**没有**做「偏差项」那个派生量（同日追加，覆盖 §7 的措辞）

### 定义先摆出来

设两个期限 T₁ < T₂，零息口径，且第 T₁ 年以后的预期短端路径走平在 L：

```
A    = 前 T₁ 年预期短端的均值        （= T₁ 那条腿的预期腿）
E_T₂ = (T₁·A + (T₂−T₁)·L) / T₂

y_T₂ − y_T₁ = (TP_T₂ − TP_T₁) + ((T₂−T₁)/T₂)·(L − A)
                                  └─ 系数 ─┘
```

T₁=10、T₂=30 → 系数 20/30 = **2/3**。系数只依赖这一组期限，换期限对要重算。

**分解式本身是干净的。** 不能用的是**拿现有输入去算 `L − A`**。

### 四层污染，叠在一起

| # | 污染 | 后果 |
|---|---|---|
| ① | L 与 A 出自**不同模型家族**：A = KW 期限结构模型（两腿同源同模型，这条干净）；L = HLW 宏观状态空间 + 市场隐含通胀远期（两个互不相干的来源） | 差里装着「HLW 眼中的锚」减「KW 眼中的十年预期」，两模型的分歧**无法与真实的 L − A 分离** |
| ② | T5YIFR 覆盖的年份不对：L 要第 11–30 年，T5YIFR 是 5y5y = 第 6–10 年 | 期限对不上；且第 6–10 年**恰好还在 A 的覆盖区间内**（A 是前 10 年均值），两边共用了一段 |
| ③ | HLW r\* 不是「第 10 年以后的预期短端」，它是**当下**的自然利率（现时状态量） | 相关但不是同一个对象 |
| ④ | 口径混用：THREEFY10 是**零息**（FRED 标题写 Zero Coupon），要对照的 30Y−10Y 来自 `treasury` 的**par yield** | 两端口径不同 |

四层近似串起来，输出一个两位小数的序列 —— **这正是 §3 那条纪律要防的东西，而且假在图上看不出来。**

### 做了什么：并排两条线，只读符号

`L − A` 的**符号**比它的量级稳健得多：

```
A > L   →  偏差项为负  →  30Y−10Y 在水平上【低估】两段溢价之差
A < L   →  偏差项为正  →  【高估】
```

短端离中性哪一边基本决定符号 —— 该判断**不依赖 2/3、不依赖口径统一、也不依赖两个模型可比**。

所以 `ratesDecomp` 的第三格是「A vs L 缺口」：`expShort10Kw`（A，日频线）叠上
`lProxyHlwT5yifr`（L 代理，**季频阶梯**）。**不做减法、不乘系数、不出单一数字。**
读法（谁在上面 → 低估还是高估）写在那格的 ⓘ 里，四层污染也全写在里面。

### 频率不统一是**要显示出来**的，不是要抹平的

季频 r\* 拼进日频，L 实际只有季度分辨率。一个季度分辨率的量，解释不了日频利差的**变动** ——
这正是别做减法的另一个理由：两条线各画各的频率（A 日频线、L 季频阶梯），
读者一眼看得出「下面那条一个季度才动一次」。**相减成单序列，这个信息就被抹平了。**

实现上因此**刻意不把 r\* 前向填充成日频**：`analytics/regime.ts` 的 `sumAtAnchorDates(anchor, daily)`
只在 r\* 的季度日出点（日频腿取 ≤ 该日的最近观测）。通胀腿的日内变动没有丢 ——
它自己在 `t5yifr` 那一格里照常是日频线。

### 架构上踩到的一个坑（已加断言）

「加一格」最初是新开第五格、主线复用 `expShort10Kw`。**这会静默坏掉**：pane key 同时是
series 键、图表 series 句柄的 Map 键（`paneChart.hooks.ts` 的 `seriesRef`）、以及
`desc` / `colors` 那几张 `Object.fromEntries` 的键。同 key 两格 → 后一格覆盖前一格的说明，
且只有一条线活下来。**不报错。**

改成把 overlay 折进已有的 `expShort10Kw` 那格（4 格，无重键），并加了两条断言：

- `REGIME_DIMS` 每个 dim 内 pane key（含 overlay）不得重复 —— 实测人为造重键会挂
- `derivePaneMeta` 要把 overlay 并进同 pane 的 `series` 并带上自己的名字/颜色

### 验到的

- `sumAtAnchorDates` 单测 2 条（含「锚点日在日频腿首个观测之前 → 跳过，不补 0」，
  以及「元旦这种非交易日锚点要取前一笔、不能取后一笔」）
- 真实数据验算术（r\* 走 fetcher，T5YIFR 走免 key 的 fredgraph）：r\* 34 点 → **L 33 点**
  （首个锚点 `2018-01-01` 因 T5YIFR 首观测在 `2018-01-02` 被跳过 —— 正是「不补 0」的实测证据）；

  （与「短端远在中性之上 → A > L」一致）
- `/api/regime`：`lProxyHlwT5yifr` 实跑 33 点落在 `series`（写这条时以为本地缺 FRED key 会归
  `unavailable`，实际 `.env` 里有 key，见 §6 末订正）；overlay 缺失时主线照画 —— 有单测覆盖
- typecheck / biome 干净（测试总数见 §9.5）

### 遗留

`认知转变记录 L189` 的措辞（「只写偏差的水平方向，不写量级」）**仍然成立、不用改**。

### 9.3 订正：HLW `r*` 不违「期限覆盖」，但违新增的「区间均值」

§8 ③ 写「HLW `r*` 不是『第 10 年以后的预期短端』，它是**当下**的自然利率」——**方向对，但归因要精确一格**：

- **按 HLW 模型自身的口径，覆盖这条它不违反**。HLW 把趋势项（`g_t`、`z_t`）设成随机游走，故 `E_t[r*_{t+h}] = r*_t` 对任意 `h` 成立——当期 `r*` 同时就是该模型对任意远期的预测。拿「覆盖不到第 11–30 年」去判它，站不住。
- **它违的是新增的上界**：式中的 `L` 是第 11–30 年的**区间均值**，而 `r*` 是一条**无期限**的稳态水平（horizon-free）。两者只在远端确实走平时重合——而「远端走平是额外前提」正是那条认知转变记录全篇的内容。

所以 `r*` 当 `L` 用的准确理由是：**同模型（违）+ 同频（违）+ 区间均值（违）**，不是覆盖不足。§8 那张表的 ③ 可据此改述。
