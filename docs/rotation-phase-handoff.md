# 攻防 tab 上格：高切低 → 通杀 → 见底 标注（handoff）

> 来源：semantic-garden 会话 `semantic-garden-1d`，2026-11-26，用户已确认。思路出自付鹏 2026.11.20 微博「高切低转通杀·Vanna 相关性挤仓复刻 2022」（semantic-garden `sources/微博/2026.11.20-高切低转通杀·Vanna相关性挤仓复刻2022/`）。
> 回测参考脚本：`docs/research/rotation_phase_backtest.py`（Python，研究用，跑法见文件头）；对照图 `docs/research/rotation_phase_backtest.png`。
> 定位：复盘 / 状态背景板。第一阶段确认晚几周没关系（不操作）；要操作的是「通杀开始」和「阶段低点」。

## 1. 输入

QQQ 收盘、XLP 收盘（攻防 tab 已有）、VIX 收盘、`hyOas`。全部日线。本版不用 VIX3M、不用周线（分型按 §5 的第一阶段 VIX 判，不按期限结构倒挂占比）。

## 2. 状态机（每日独立推进，四态：正常 / 高切低 / 通杀 / 见底）

| 状态 | 进入（当天收盘可算） | 退出 / 作废 |
|---|---|---|
| 高切低 | 同时：① QQQ 距 250 日高点 ≤ −5% ② XLP 距 60 日高点 ≥ −2% ③ XLP 60 日涨幅 ≥ +2% ④ XLP/QQQ 比值 60 日变化 ≥ +10%。**另：当天 `hyOas` ≥ 6% → 记为「信用危机型，不算」，冷却 180 天不再判** | QQQ 回到距 250 日高点 −3% 以内 → 本轮作废（记「未通杀」） |
| 通杀 | 高切低中：XLP 从本轮高点回撤 ≥ 5% **且** VIX ≥ 25。**另：本轮 QQQ 高点到 XLP 高点不足 20 个交易日 → 记「不算·第一阶段太短」，冷却 60 天** | XLP 再创本轮新高 → 退回高切低 |
| 见底 | 通杀中：底候选（§4 的 A 点里 QQQ 最低的一天）之后 QQQ 反弹 ≥ 10% **且** VIX < 25 | QQQ 跌破该底且当天 VIX ≥ 30 → 退回通杀；跌破但 VIX < 30 = 背离，底保留。QQQ 回到距高点 −3% 内或确认后满 120 天 → 回正常 |

- 本轮 XLP 高点：在 `max(本轮 QQQ 高点日, 上一轮底日)` 之后找，避免与上一轮重叠。
- 「续段」标签：新一轮 QQQ 高点价 < 上一轮 QQQ 高点价，且距上一轮底 < 2 年。

## 3. 三条竖线 + 确认虚线（倒推到极值日画）

| 线 | 颜色 | 位置 | 确认虚线 |
|---|---|---|---|
| ① | 蓝 `#2563eb` | 本轮 QQQ 250 日高点 | 进入高切低那天 |
| ② | 紫 `#7c3aed` | 本轮 XLP 高点 | 进入通杀那天 |
| ③ | 绿 `#16a34a` | 底（§2 见底的底候选） | 进入见底那天 |

- 确认虚线：灰 `#737373`、细、虚线。
- 未确认的线（如进行中这轮的 ②）用同色淡显 / 虚线并随 XLP 新高后移，标「待定」。
- 底色：① → ② 黄 `#f59e0b`（透明度约 0.15）；② → ③ 红 `#ef4444`（约 0.15）；进行中的一轮从 ① 画到今天。

## 4. 阶段低点（三角标在 QQQ 线上；只在**进入通杀之后**才开始找）

- **A（绿 ▲ `#16a34a`）**：通杀期内 VIX ≥ 30 的日子按簇分（相隔 > 7 个自然日算新一簇）；某簇的 VIX 峰 ≥ 通杀以来 VIX 最高的 90% → 该簇里 QQQ 收盘最低那天记 A。当天收盘可见。
- **B（橙 ▲ `#f97316`）**：日线 QQQ 枢轴低点（前后各 5 个交易日内最低），与 120 天内前一个价格更高的枢轴低点比，**日线 RSI(14) 或 MACD 线（12,26,9 的 DIF）任一**更高（底背离），且该低点当周（往前 4 个自然日内）VIX 最高 ≥ 30。需低点后 5 个交易日确认，约晚一周。
- A、B 同日 = 更可靠（历史三次全中：2001-04-04、2022-06-16、2022-10-14）。

## 5. 分型与「站稳 30」

- 分型：本轮第一阶段（① → 通杀前）VIX 曾 ≥ 30 → 标「磨底型」；否则「V 形」。显示在格子标题或状态栏。
- 站稳 30：通杀期内 VIX 连续两日收盘 ≥ 30 的第一天，VIX 子格（或上格底部）标红方块 `#b91c1c`。读法：磨底型里 = 通杀开始（减仓 / 对冲，不是抄底）；V 形里出现时基本就是底。
- 第一阶段 VIX ≥ 30 的日子标小红 ▼（可选）。
- 本版**不用**周线背离；不做「强 / 弱」两档。
