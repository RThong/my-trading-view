# 期权结构 / 踩踏监控面板 —— 实现规格（handoff）

> 来源：semantic-garden 会话 `semantic-garden-1d`，2026-11-21。参照付鹏「美股期权微观结构与流动性踩踏监控仪表盘」（静态网页，源码存档于 semantic-garden `sources/纯文稿/2026.11.19-美股期权微观结构与流动性踩踏监控仪表盘/`），按我们能拿到的数据改写，并经 2018 年起回测选定方案。
> 定位：**与恐慌同步的状态背景板，不是择时信号**。回测里各系统进入"阶段三"平均只领先恐慌起点 1–3 个交易日。

## 0. 已定的设计决定（不要再改）

1. **不做总分**（不复刻付鹏的"71/100 压力指数"）。**v2（用户 11-21 改）：每个维度各打一个分（0–100），五个分并排，不合成总分**，算法见 §10。理由：权重主观、两个 gamma 口径混用、说不出分数含义；Codex 评审同意。
2. **阶段判定沿用付鹏原规则的结构与绝对阈值**（删去我们没有数据的条款）。回测对比过"全分位状态机"和"合并版"，付鹏版误报最少、2022 熊市里没有过早报"修复"，故选它；不再调参（只有 15 个事件）。
3. **每个指标同时显示原值和分位**：分位 = 该序列截至**前一交易日**的滚动 5 年分位（不足 5 年用扩张窗口，满 252 个观测才显示）。分位只表示稀有度，不表示损失概率。
4. **做市商维度只用 Squeezemetrics `gex`**，按它自身分位读，不看零轴正负；不接朴素口径 GEX（`feat/dhawalc-gex` 继续搁置）、不接 Nomura / SpotGamma。单位按白皮书是"每 SPX 1 点"（dashboard 文档若写"每 1% 变动"需订正，见末节）。
5. 阶段四改名 **「风暴暂歇」**，不叫"修复"：回测里阶段四之后 21 日回撤≥5% 的比例（27–28%）高于基准（18%）。

## 1. 数据（`/api/regime` 已有键）

`vix` `vix9d` `vixVix3m`(=VIX/VIX3M) `vix9dVix` `vvix` `skew` `vixeqVix` `dspx` `cor1m` `cor3m` `corTermSpread` `pcEquity` `pcIndex` `pcTotal`（及 `Ma5/Ma20/Ma63`）`gex`。P/C 2019-10-07 起，其余 2018 起（分位暖机可用更早的 CBOE CSV / Squeezemetrics DIX.csv）。

## 2. 阶段判定（每日独立判定、无记忆，优先级 三 → 一 → 四 → 二）

| 阶段 | 条件（P/C 用当日值） |
|---|---|
| **三 风暴**（负反馈翻转 / Vanna 踩踏） | `vix >= 26 且 (vixVix3m >= 1 或 vvix >= 110)` |
| **一 稳态**（缩圈离散） | `vix < 18 且 skew < 158` |
| **四 风暴暂歇** | `vixVix3m < 1 且 vvix < 110 且 skew < 155 且 vixeqVix < 2.0` |
| **二 预警 / 过渡** | 其余 |

付鹏原规则另有的条款已删去并须在面板说明里注明：阶段三的 `DealerGamma <= -4.5 且 GEX <= -50B` 分支；阶段一的 `DealerGamma >= 1.5 且 GEX >= 25B`；阶段四的 `NetDelta >= 0 且 GEX < 25B`。

## 3. 两个转换点（单独亮灯，不是阶段）

- **断崖**：`vixeqVix` 过去 20 个交易日（t−20…t−1）内分位最高值 ≥90，且当日分位 ≤50。（付鹏原文"VIXEQ/VIX 高位断崖回落"。回测中常比阶段三早几个交易日：2024-08-02→08-05、2026-03-03→03-06。）
- **升级（宏观全面防御）**：`pcIndex >= 1.25 且 pcEquity >= 0.80`（付鹏绝对值；分位版太迟钝，回测只亮过一次）。2019-10 起在 4 次恐慌的阶段三里亮过：2020-02-25、2022-01-21、2022-04-22、2024-08-08；7 段，之后 21 日回撤≥5% 比例 40%（全场最高）。

## 4. 顶部状态行（格式示例）

`阶段三 · 风暴（第 4 天，本轮自 11-05 起）｜断崖 ● 升级 ○｜风险清单 1/4 · 暂歇清单 0/4`

| 维度 | 指标 | 付鹏黄线 / 红线（照原样标注，供参照） |
|---|---|---|
| 离散与相关性 | `vixeqVix`、`dspx`、`cor1m` / `cor3m` / `corTermSpread` | VIXEQ/VIX 黄 <2.15、红 <1.85；DSPX 黄 <39、红 <35 且 VIX>25 |
| 波动率 | `vix`、`vix9d`、`vvix` | VIX 黄 ≥20、红 ≥28；VVIX 黄 ≥100、红 ≥115 |
| 期限结构与偏度 | `vixVix3m`、`vix9dVix`、`skew` | 两个比值 黄 ≥0.95、红 >1.00；SKEW 黄 ≥160，红 = VIX≥25 时 SKEW<150 |

## 6. 两张清单（自动判定）

**风险升级**（满足越多，向全市场扩散的风险越高）

**风暴暂歇**（满足越多，空头回补概率越高）

2. `vvix < 110`

## 7. 历史分布说明（面板上作为"读法"文字，2018-01 至 2026-11，标普 21 日前瞻；基准：收益中位 +1.7%、期间回撤≥5% 占 18%）

| 阶段（付鹏版） | 时间占比 | 21 日收益中位 | 回撤≥5% |
|---|---|---|---|
| 一 稳态 | 47.8% | +1.4% | 14% |
| 二 预警 / 过渡 | 23.2% | +1.4% | 18% |
| 三 风暴 | 10.5% | **+5.1%** | 23% |
| 四 风暴暂歇 | 18.5% | +1.5% | **28%** |

读法：阶段三 = 已在风暴里、两头放大（多数随后反弹，不是卖出信号）；阶段四 = 风暴暂歇、不是见底确认（2022 年 5–6 月 VIX 28–30 时就多次闪现）。15 次恐慌中阶段三命中 12 次（漏 2018-04、2023-10 两次纯回撤事件与 2018-11 晚 18 天），误报 7 段、每段 1–2 天。样本小，只作方向参考。

**页面自上而下四块，主视图不放成段文字**（规则、删去的条款、历史分布表、读法全部收进 ⓘ 悬停）：

1. **阶段卡一排**（照付鹏 STAGE 01–04）：四张卡并排，当前阶段红框 +「当前」角标，其余标「已经过 / 观察中」。卡内只一行副标题。卡排右上两个小徽标：`断崖 ●/○`、`升级 ●/○`。下面一行显示「第 N 天，本轮自 MM-DD 起」。
2. **五个维度分数条**：一行五个小块，各写维度名 + 分数（0–100）+ 颜色（<34 绿、34–66 黄、≥67 红）。**不合成总分。**
3. **五维度卡片**（照付鹏版面）：每个维度一张卡，卡头 = 维度名 + 一行说明 + 本维度分数徽标。每个指标一行，内容依次为：
   - 色点
   - 指标名，下面一行灰字写红线
   - 数值框
   - 状态标签「正常 / 警戒 / 触发红线」
   - 下面一根横条：**横条 = 滚动 5 年分位 0–100**，圆点 = 当前分位，细竖线 = 付鹏红线对应的分位（§5 那串 P 值）

   原值、分位数字、20 日变化放悬停。每张卡只留付鹏原有的指标：
   - 离散：VIXEQ/VIX、DSPX。COR 三条移出本页，情绪 tab 已有。
   - 波动率：VIX、VVIX。
   - 期限：VIX/VIX3M、VIX9D/VIX、SKEW。
   - 流量：个股、全市场、指数 P/C。
   - 做市商：GEX。
4. **两张清单**（照付鹏左红右绿两框）：每项一行，带「已触发 / 未触发」标签，替代项后面挂小字「替代」。框头写「风险 1/4」「暂歇 0/4」。

**历史大图**：默认收起（折叠按钮「看历史」）。展开后只画标普 + **阶段三红底**（可选阶段四蓝底），不画阶段一 / 二底色，不画断崖竖线和升级细带。断崖、升级只在阶段卡徽标上亮。

**维度分数算法**（简单、和卡片标签同口径，用户一眼能对上）：
- 每个指标按付鹏线亮灯：触发红线 = 100，警戒 = 50，正常 = 0。维度分 = 该维度指标的平均分，四舍五入。
- 黄 / 红线照 §5（SKEW 用复合规则：VIX≥25 且 SKEW<150 记红，SKEW≥160 记黄）。
- GEX 没有付鹏线可用，按分位：≤5 记红，≤20 记黄。
- 缺数（用户定）：只按有数据的指标求平均，分数旁标「缺 n 项」。DSPX / SKEW 的红线要看 VIX，VIX 缺数时这两项记无数据。
- 分数只表示"本维度几条线亮了"，不是概率。ⓘ 里写明这句。
